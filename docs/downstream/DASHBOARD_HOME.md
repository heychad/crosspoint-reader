# Dashboard Home

Dashboard Home shows the previewed cover, book/chapter text, and the selected RC2
reading fields. Clock-based rows include dates and daily average; clockless rows
show sessions and average session. The device footer shows streak and reading
period with a clock, or device totals without one. Landscape uses a statistics
grid. Missing data remains unavailable.

Saved theme value 6 remains unchanged. See [Home presentation](HOME_PRESENTATION.md)
for data ownership, memory bounds, source comparison, checks, and device validation.
