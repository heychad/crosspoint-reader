# Home-button reader shortcuts

Home-button tap, double-tap, and hold can be assigned to Browse Files, Library,
Saved Items, File Transfer, or Reading statistics. These choices act inside an
open book and do nothing on other screens. Keep another Home gesture if you
want a Home shortcut outside the reader.

The new choices append values 14–18 and preserve existing assignments. Older
firmware may reset the new choices on downgrade. Reader overlays, end-of-book
menus, and Quick Lock retain input ownership. When a screen hands off while a
Home contact is held, its remaining edges are discarded through release. The
reader stops automatic page turning before opening a shortcut and uses its
existing save and navigation paths. File Transfer opens the mode chooser.

No new tasks, persistent files, or recurring allocations are added. X4 Pro
physical input timing, orientation, and each destination need device checks.
