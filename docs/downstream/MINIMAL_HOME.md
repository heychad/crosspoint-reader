# Minimal Home

Minimal Home shows a rounded cover, saved reading time, and whole-book progress.
It uses the compact Home gestures and shared Menu, with cover taps opening the
previewed book. The cover and thumbnail adapt to the current orientation;
missing artwork uses the native placeholder and book title.

Saved theme value 5 remains unchanged. Source files and reading state stay in
their existing locations. See [Home presentation](HOME_PRESENTATION.md) for the
current RC2 comparison, resources, checks, and remaining device validation.
