# Reader bar settings from a book

The EPUB reader menu and toolbar **More** panel include **Reader bar layouts**. This opens the existing global top and bottom bar settings without leaving the book. On return, the reader saves the current content anchor and rebuilds the chapter layout so changes to bar height can repaginate around the same reading position.

The menu uses one extra fixed row. When a footnote or link return is pending, the menu asks the reader to return from the link first: those returns use page numbers from the old layout. If the settings screen or notice cannot be allocated, the reader stays on its existing page. Physical checks are still needed for book position, link returns, bar appearance, orientation changes, and the More panel on the X4 Pro.
